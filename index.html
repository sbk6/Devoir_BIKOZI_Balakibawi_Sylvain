Contexte du Projet

Ce projet met en place une architecture serverless hautement disponible pour ingerer en temps réel les flux de données envoyés par des milliers de capteurs IoT industriels via des requêtes HTTP POST. En parallèle, un site de documentation est accessible de manière sécurisée via Amazon CloudFront et un bucket S3 privé avec Origin Access Control (OAC).

Toute l'infrastructure est automatisée avec AWS CloudFormation (< template.yaml >).

Traitement Lambda (index.py)

La fonction Lambda index.handler exécute les étapes suivantes à chaque requête :

  1. Extraction et parsing du corps JSON de la requête HTTP
  2. Calcul de la température moyenne et du nombre d'anomalies (status=ERROR)
  3. Sauvegarde du payload brut dans S3 : raw-zone/year=YYYY/month=MM/<uuid>.json
  4. Enregistrement du rapport dans DynamoDB : request_id, timestamp, s3_path, avg_temperature, error_count
  5. Retour HTTP 201 Created

Exemple de payload d'entrée

{
  "records": [
    { "sensor_id": "sensor-001", "temperature": 23.5, "status": "OK"    },
    { "sensor_id": "sensor-002", "temperature": 41.2, "status": "ERROR" },
    { "sensor_id": "sensor-003", "temperature": 19.8, "status": "OK"    },
    { "sensor_id": "sensor-004", "temperature": 55.0, "status": "ERROR" }
  ]
}

Réponse attendue (HTTP 201)

{
  "message": "Donnees ingestion reussie",
  "request_id": "a1b2c3d4-...",
  "s3_path": "raw-zone/year=2026/month=06/a1b2c3d4-....json",
  "avg_temperature": 34.88,
  "error_count": 2
}

Commandes de Déploiement

1. Déployer le stack CloudFormation

aws cloudformation create-stack \
  --stack-name devoir-sbikozi \
  --template-body file://infrastructure/template.yaml \
  --capabilities CAPABILITY_NAMED_IAM \
  --region eu-west-3

2. Uploader la documentation dans S3

aws s3 cp index.html s3://sbikozi-tech-doc-629193321657/ --region eu-west-3

3. Tester le pipeline

pip install requests
python test_client.py
